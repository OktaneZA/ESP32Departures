Departure Buddy

Live UK trains, London buses and Thames river boats on a small desk board. Set it up here, then send it straight to the device.

1 Board basics

2.4GHz only — the ESP32-S3 has no 5GHz radio. This is the single most common reason a board will not connect.

Everything on this page stays in your browser. Nothing is sent anywhere — the settings go straight down the USB cable to your board.

5 Send it to your board

Configure over USB recommended

Plug the board in, click below, and pick it from the list. Your settings never leave this computer.

Your browser can’t talk to USB devices

Direct configuration needs Chrome, Edge or Opera on a desktop. In Firefox and Safari, download the settings file below and drop it onto the Windows installer.

Or download a settings file

Save this, then drag it onto DepartureBuddyInstaller.exe. It flashes the board and applies these settings.

Heads up: this file contains your WiFi password in plain text, so it can set the board up without you retyping anything. Keep it somewhere sensible and delete it when you’re done — the installer offers to do that for you.
